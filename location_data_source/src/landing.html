Available Endpoints

All endpoints return standard JSON with pagination and support case-insensitive keyword search.

GET /api/states
List all 36 States and Union Territories
GET /api/districts?stateCode=18
Filter 784 districts by state code or name
GET /api/subdistricts?districtCode=310
List 7,092 subdistricts (tehsils/talukas)
GET /api/cities?q=delhi
Search 5,050+ urban local bodies / cities
GET /api/search?q=moranhat
Unified cross-collection search
GET /api/metadata
Dataset synchronization metadata and counts
